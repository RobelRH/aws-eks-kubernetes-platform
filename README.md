# AWS EKS Kubernetes Platform

A production-style Kubernetes platform built on Amazon EKS using Terraform, Docker, Helm, GitHub Actions, and cloud-native observability.

## Project Goals

This project demonstrates:

- Infrastructure provisioning with Terraform
- Kubernetes orchestration with Amazon EKS
- Containerized application deployment
- Helm-based application packaging
- CI/CD with GitHub Actions
- Secure AWS authentication using GitHub OIDC
- Kubernetes health checks and rolling deployments
- Autoscaling
- Monitoring and observability
